# Kenko v1.9.0 全链路轻量抛光 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 按 2026-09-01 抛光设计实现 App 使用/训练记录/显示/查询/动作记录/页面显示 6 流程各 1-2 点等权抛光，AddSet 三行等宽对齐与长按连发、动作库二级筛选置顶与行内创建、卡片三档字阶与空状态统一，无 DB migration。

**Architecture:** 复用现有 DraggableTextField + FilterChip + MaterialTheme 体系，新增状态仅 UI 层 rememberSaveable 存放二级筛选 All/部位->肌肉；AddSet 容器等宽对齐通过 Modifier.fillMaxWidth 与等宽按钮实现；字阶统一为 titleSmall/numbers/labelSmall 三档。

**Tech Stack:** Kotlin 2.2, Jetpack Compose BOM 2025.11.00, Material 3 Expressive, Hilt, Room（不动）、Navigation Compose、DataStore

## Global Constraints

- DB 微调需告知，本版不产生 migration 13→14

  在 `AddSet.kt:305-321` 将 `Surface modifier = modifier.requiredHeight(44.dp)` 改为 `modifier.fillMaxWidth().requiredHeight(44.dp)`，`Row` 增加 `horizontalArrangement = Arrangement.SpaceBetween`，`DraggableTextField` 保持 `zIndexModifier`，按钮侧用固定宽度。
  ```kotlin

      Row(modifier = Modifier.fillMaxWidth(), horizontalArrangement = Arrangement.SpaceBetween, verticalAlignment = Alignment.CenterVertically) { content() }

  ```

- [ ] **Step 3: 按钮等宽与占位**

  ```kotlin

  CompactStepButton(modifier = Modifier.width(48.dp), ...)
  ```

- [ ] **Step 4: 长按连发**
  在 `AddSet.kt` 的步进按钮外层包 `Modifier.pointerInput` 或使用 `combinedClickable` + `LaunchedEffect` 实现长按 400ms 后每 80ms `viewModel.addRep/addWeight` 连发，松开取消。复用 `AddSetViewModel.addRep` 现有边界 `boundReached` 不额外处理。
  ```kotlin

  LaunchedEffect(pressed) { while(pressed) { delay(80); viewModel.addRep(1) } }
  ```

- [ ] **Step 5: 编译与视觉走查**
  运行: `./gradlew assembleDebug`
  预期: 三行等宽对齐，横屏/深色主题无折行，长按连发不溢出边界。

- [ ] **Step 6: Commit**
